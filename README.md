# FC27 SCOUT — Player Position Predictor

ML-сервис многоклассовой классификации, который предсказывает основную игровую позицию футболиста по его техническим, физическим и игровым характеристикам.

Проект включает полный цикл машинного обучения: исследование данных, предобработку, обучение и сравнение моделей, REST API на FastAPI и веб-интерфейс.

## 1. Данные

Используется датасет EA SPORTS FC27 Player Ratings.

- Количество записей: 19 789.
- Количество исходных столбцов: 60.
- Целевая переменная: `position`.
- Количество классов: 12.

Исходный файл необходимо разместить по пути:

`data/players.csv`

### Предобработка данных

В процессе подготовки данных:

- удаляются записи без целевой переменной;
- проверяются и преобразуются типы данных;
- обрабатываются пропущенные значения;
- исключаются идентификаторы, имена, метаданные и потенциально протекающие признаки;
- исключаются полностью пустые столбцы `height_cm` и `weight_kg`;
- используются числовые игровые характеристики и признак `preferred_foot`;
- данные разделяются на обучающую и тестовую выборки в соотношении 80/20 с сохранением распределения классов.

Для числовых признаков применяется заполнение пропусков медианой и стандартизация. Для категориального признака применяется заполнение наиболее частым значением и One-Hot Encoding.

## 3. Обучение моделей

Для решения задачи многоклассовой классификации сравниваются две модели:

1. Logistic Regression
2. Random Forest Classifier

Основная метрика выбора модели — macro ROC-AUC с подходом One-vs-Rest (OvR).

Дополнительно оцениваются Accuracy и macro F1-score.

### Результаты эксперимента

| Модель | Accuracy | Macro F1 | ROC-AUC OvR |
|---|---:|---:|---:|
| Logistic Regression | 0.7415 | 0.6261 | 0.9631 |
| Random Forest | 0.7524 | 0.6042 | 0.9611 |

По основной метрике ROC-AUC выбрана Logistic Regression.

Обученная модель сохраняется в:

`models/best_model.pkl`

Отчёт со сравнением моделей сохраняется в `reports/model_comparison.csv`.

## 5. Установка и запуск

### Создание виртуального окружения

Windows PowerShell:

```powershell
python -m venv .venv
```

Установка зависимостей:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### Исследование и подготовка данных

```powershell
.\.venv\Scripts\python.exe eda.py
.\.venv\Scripts\python.exe preprocessing.py
```

### Обучение моделей

```powershell
.\.venv\Scripts\python.exe train.py
```

После обучения лучшая модель будет сохранена в `models/best_model.pkl`.

### Запуск API

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

API будет доступен по адресу:

http://127.0.0.1:8000

Документация Swagger:

http://127.0.0.1:8000/docs

### Запуск frontend

Открой файл `frontend/index.html` в браузере.

Веб-интерфейс позволяет вводить характеристики футболиста, получать предсказанную позицию и загружать CSV-файлы для массовой обработки.

## 6. API

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/` | Информация о сервисе |
| GET | `/health` | Проверка состояния сервиса |
| POST | `/upload-model` | Загрузка модели |
| POST | `/predict` | Предсказание позиции игрока |
| POST | `/predict-from-csv` | Массовое предсказание из CSV |

### POST /predict

Принимает JSON-объект с характеристиками одного игрока или список игроков в поле `players`.

Результат содержит:
- исходные характеристики;
- предсказанную позицию;
- вероятности принадлежности к каждому классу.

### POST /predict-from-csv

Принимает CSV-файл с признаками, использованными при обучении модели.

Возвращает:
- количество обработанных записей;
- предсказанные позиции;
- метрики Accuracy и macro F1, если в CSV присутствует целевая переменная `position`;
- ROC-AUC OvR, если его можно рассчитать для переданных данных.

## 8. Ограничения проекта

- Модель является учебной и воспроизводит закономерности исходного датасета.
- Предсказание не является объективной оценкой футбольных способностей игрока.
- Качество классификации зависит от распределения классов и качества исходной разметки.
- Вероятности модели не следует трактовать как гарантированную точность предсказания.
- Для загрузки моделей разрешается использовать только доверенные файлы: форматы Pickle и Joblib могут выполнять код при загрузке.

Проект демонстрирует полный путь от анализа данных и обучения моделей до развёртывания REST API и взаимодействия с пользователем через веб-интерфейс.
