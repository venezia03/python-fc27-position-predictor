# FC27 SCOUT — Player Position Predictor

**FC27 SCOUT** — ML-сервис многоклассовой классификации, который предсказывает основную игровую позицию футболиста по его техническим, физическим и игровым характеристикам.

Проект демонстрирует полный цикл разработки ML-приложения: исследование данных, предобработку, обучение и сравнение моделей, создание REST API на FastAPI, веб-интерфейс и автоматическое тестирование с помощью SourceCraft CI.

---

## 1. Данные

Используется датасет **EA SPORTS FC27 Player Ratings**.

Основные характеристики:
- Количество записей: 19 789.
- Количество исходных столбцов: 60.
- Целевая переменная: `position`.
- Количество классов: 12.

Исходный файл необходимо самостоятельно разместить по пути:

`data/players.csv`

Датасет не включён в Git-репозиторий.

### Предобработка данных

В процессе подготовки данных выполняются следующие действия:

- удаление записей без целевой переменной;
- проверка и преобразование типов данных;
- обработка пропущенных значений;
- исключение идентификаторов, имён, метаданных и потенциально протекающих признаков;
- исключение полностью пустых столбцов `height_cm` и `weight_kg`;
- использование числовых игровых характеристик и категориального признака `preferred_foot`;
- разделение данных на обучающую и тестовую выборки в соотношении 80/20 с сохранением распределения классов.

Для обработки признаков используются:
- числовые признаки: заполнение пропусков медианой и стандартизация `StandardScaler`;
- категориальные признаки: заполнение наиболее частым значением и `OneHotEncoder`.

После предобработки используются 43 признака.

## 4. Обучение и сравнение моделей

Для решения задачи многоклассовой классификации сравниваются две модели:

1. Logistic Regression.
2. Random Forest Classifier.

Основная метрика выбора модели — **Macro ROC-AUC** с подходом One-vs-Rest (OvR).

Дополнительно оцениваются:
- Accuracy;
- Macro F1-score.

### Результаты эксперимента

| Модель | Accuracy | Macro F1 | ROC-AUC OvR |
|---|---:|---:|---:|
| Logistic Regression | 0.7415 | 0.6261 | **0.9631** |
| Random Forest | **0.7524** | 0.6042 | 0.9611 |

По основной метрике ROC-AUC выбрана **Logistic Regression**.

Несмотря на немного более высокую Accuracy у Random Forest, Logistic Regression показала лучший результат по основной метрике эксперимента.

Обученная модель сохраняется в:

`models/best_model.pkl`

Отчёт со сравнением моделей:

`reports/model_comparison.csv`

## 6. Установка и запуск

### 6.1. Клонирование репозитория

```bash
git clone https://github.com/venezia03/python-fc27-position-predictor.git
cd python-fc27-position-predictor
```

### 6.2. Создание виртуального окружения

Windows PowerShell:

```powershell
python -m venv .venv
```

### 6.3. Установка зависимостей

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 6.4. Подготовка данных

Разместить исходный датасет по пути:

`data/players.csv`

Запустить исследование данных и предобработку:

```powershell
.\.venv\Scripts\python.exe eda.py
.\.venv\Scripts\python.exe preprocessing.py
```

### 6.5. Обучение моделей

```powershell
.\.venv\Scripts\python.exe train.py
```

После обучения:
- сравниваются Logistic Regression и Random Forest;
- рассчитываются метрики качества;
- сохраняется отчёт сравнения;
- лучшая модель сохраняется в `models/best_model.pkl`.

### 6.6. Запуск API

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

API будет доступен по адресу:

http://127.0.0.1:8000

Документация Swagger:

http://127.0.0.1:8000/docs

### 6.7. Запуск Frontend

Открыть файл `frontend/index.html` в браузере.

Веб-интерфейс позволяет:
- вводить характеристики футболиста;
- получать предсказанную игровую позицию;
- просматривать вероятности принадлежности к классам;
- загружать CSV-файлы для массовой обработки.

Для работы интерфейса API-сервер должен быть запущен.

## 7. REST API

В приложении реализованы следующие endpoints:

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/` | Информация о сервисе |
| GET | `/health` | Проверка состояния сервиса |
| POST | `/upload-model` | Загрузка модели |
| POST | `/predict` | Предсказание позиции игрока |
| POST | `/predict-from-csv` | Массовое предсказание из CSV |

### POST `/predict`

Принимает JSON-объект с характеристиками одного игрока или список игроков в поле `players`.

Результат содержит:
- исходные характеристики;
- предсказанную игровую позицию;
- вероятности принадлежности к каждому классу.

### POST `/predict-from-csv`

Принимает CSV-файл с признаками, использованными при обучении модели.

Возвращает:
- количество обработанных записей;
- результаты предсказаний для записей файла.

Для проверки и отправки запросов можно использовать Swagger:

http://127.0.0.1:8000/docs

## 10. Ограничения проекта

- Модель является учебной и воспроизводит закономерности исходного датасета.
- Предсказание не является объективной оценкой футбольных способностей игрока.
- Качество классификации зависит от распределения классов и качества исходной разметки.
- Вероятности модели не следует трактовать как гарантированную точность предсказания.
- Для загрузки моделей разрешается использовать только доверенные файлы: форматы Pickle и Joblib могут выполнять код при загрузке.
